# Notebook

Append-only research journal for active work.

## Structure

```text
notebook/
  archive/   historical dumps and old mixed notes; not chronological
  journal/   append-only daily notes
```

## Journal Rules

1. Add new entries to `notebook/journal/YYYY-MM-DD.md`.
2. Use this entry format:

   ```text
   ## HH:MM - Short Title
   ```

3. Do not rewrite old entries to change the story. If an interpretation changes,
   append a correction or follow-up entry.
4. Archive files are allowed to be messy. They are snapshots, not ordered logs.
5. Promote stable cleaned-up material into `docs/` later.
