# Notes Index

Project notes are organized by topic. Put new notes in the closest existing
topic directory rather than at the root.

- `core/` — AGPT mathematical definition, model sketches, invariants, and MVP plans.
- `trainer/` — trainer implementations, schedules, runtime bottlenecks, and CUDAX parity.
- `trie-structure/` — trie/radix representations, compression, virtual trees, and subtree attention.
- `prefix-suffix/` — prefix/suffix bridges, folding, suffix blending, and topological navigation.
- `seq-len-extension/` — position, RoPE, harmonic-filter, and longer-context work.
- `optimization/` — optimizer, curvature, Fisher, trust weighting, and distillation notes.
- `operations/` — project/process infrastructure, experiment runner, and repository split notes.
- `archived-subagent-work/` — historical delegated work artifacts.

Do not use `notes/agpt/`. That path is a retired holdover from when AGPT and
microgpt were organized together.
