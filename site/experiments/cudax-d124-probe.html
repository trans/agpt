CUDAX depth-124 probe

Can the CUDAX v2 trainer train a d64 L2 model on the full depth-124 Shakespeare trie, and how does held-out PPL move with the number of static epochs?

THE ANSWER SO FAR

It trains. Held-out rolling byte PPL falls monotonically from 16.21 at 1 epoch to 7.47 at 25 epochs (5226 s of training) and is still falling at the end. The README never recorded a hypothesis or conclusion, there is no depth-16 control in the directory, and the probe was not followed up here.
